# windows

## windows-optimize.bat：Windows 优化

双击运行，自动提权后打开图形窗口（WPF，微软雅黑，不显示命令行窗口）。勾选项目后点「执行所选」；「全选 1-9」「清空」在底栏；「状态检查」只读不改；「恢复到优化前」按记录还原。左侧每项右上角显示执行或检查结果，右侧「运行记录」显示过程。

| 序号 | 内容 |
|---|---|
| 1 | 性能：后台应用（策略禁止，白名单放行）、Edge 后台常驻与启动加速、视觉效果、电源模式（仅「平衡」计划、插电时） |
| 2 | 服务、开机启动项、关闭快速启动、台式机关闭休眠（勾选后可选同时禁用打印服务） |
| 3 | 卸载小组件，并用策略防止重装 |
| 4–7 | 隐私：搜索 / 遥测 / 广告推荐 / 输入语音 Copilot Recall |
| 8 | 禁用数据收集计划任务 |
| 9 | 清理 Temp 中 1 天以前的文件；勾选后可选清理 WinSxS 旧组件（DISM，需几分钟） |
| 10 | 移动用户文件夹到其他盘（勾选后填目标目录，默认 `D:\Users`；不在「全选」中） |

### 本机配置

脚本开头「本机配置」区集中了与具体电脑有关的设置，换电脑时只改这里：允许后台运行的应用（包系列名）、要关闭的音频托盘启动项和计划任务、Temp 保留目录与清理天数、用户文件夹默认目标盘。

### 状态检查

「状态检查」只读不改：逐项比对 1-9 的当前值与目标值，列出未生效的项。Windows 大版本更新常会还原推广内容、计划任务等设置，更新后跑一次，标黄的项重新执行即可。注册表值显示已生效不等于该版本一定遵守（见下方版本限制）。

### 恢复

- 每个注册表值、服务、计划任务第一次被修改前，原状态记录在 `%LOCALAPPDATA%\WindowsOptimize\undo.json`，以后重复运行不会覆盖。「恢复到优化前」按记录逆序还原（新建的值和键会删除），恢复失败的项保留在记录里。
- 首次执行时另建一个系统还原点（需在「系统属性 → 系统保护」里开启 C 盘保护）。
- 卸载的应用（小组件、Copilot）需在 Microsoft Store 手动重装；序号 10 的文件夹位置不在恢复范围内。
- 运行日志在同一目录的 `log.txt`（「运行记录」面板的「打开日志目录」）。

### 注意

- 需用管理员账户登录后运行；标准用户提权到另一个账户时脚本会拒绝执行，否则用户级设置会写错账户。
- 序号 1 用策略 `LetAppsRunInBackground=2` 禁止商店/MSIX 应用后台运行，白名单为 Claude 和开始菜单、搜索、安全中心等系统组件（在脚本 `$bgAllow` 里添加）；普通桌面程序不受影响。被禁的商店应用（如「手机连接」、邮件）后台通知会失效。Edge 策略生效后 `edge://settings` 会显示「由你的组织管理」。
- 遥测级别、CloudContent / 聚焦类策略在家庭版、专业版上有上限或不生效，脚本会提示。
- 序号 2 按 `PCSystemType` 判断机型，只在台式机上执行 `powercfg /hibernate off`（删除约为内存 40% 大小的 `hiberfil.sys`），可恢复。
- 序号 9 的组件清理用 `StartComponentCleanup`，不加 `/ResetBase`，已安装的更新仍可卸载；此项不可恢复，也无需恢复。
- 序号 8 关闭兼容性评估任务后，大版本功能更新前的兼容性检查会受影响。
- 序号 10：先关闭 OneDrive 的文件夹备份；目标须为 NTFS/ReFS 固定磁盘，新文件夹权限只给本人、SYSTEM 和管理员组；有文件移动失败时该文件夹位置不改，关闭占用程序后重跑即可。
