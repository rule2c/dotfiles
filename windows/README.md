# windows

## windows-optimize.bat：Windows 优化

双击运行，自动提权，按序号多选（如 `1 4 6`；`a` 执行 1-9；`r` 恢复；`q` 退出）。

| 序号 | 内容 |
|---|---|
| 1 | 性能：后台应用、视觉效果、电源模式（仅「平衡」计划、插电时） |
| 2 | 服务、开机启动项、关闭快速启动（打印服务单独询问） |
| 3 | 卸载小组件，并用策略防止重装 |
| 4–7 | 隐私：搜索 / 遥测 / 广告推荐 / 输入语音 Copilot Recall |
| 8 | 禁用数据收集计划任务 |
| 9 | 清理 Temp 中 24 小时以前的文件 |
| 10 | 移动用户文件夹到其他盘（默认 `D:\Users`，不含在 `a` 中） |

### 恢复

- 每个注册表值、服务、计划任务第一次被修改前，原状态记录在 `%LOCALAPPDATA%\WindowsOptimize\undo.json`，以后重复运行不会覆盖。菜单 `r` 按记录逆序还原（新建的值和键会删除），恢复失败的项保留在记录里。
- 首次执行时另建一个系统还原点（需在「系统属性 → 系统保护」里开启 C 盘保护）。
- 卸载的应用（小组件、Copilot）需在 Microsoft Store 手动重装；序号 10 的文件夹位置不在恢复范围内。
- 运行日志在同一目录的 `log.txt`。

### 注意

- 需用管理员账户登录后运行；标准用户提权到另一个账户时脚本会拒绝执行，否则用户级设置会写错账户。
- 遥测级别、CloudContent / 聚焦类策略在家庭版、专业版上有上限或不生效，脚本会提示。
- 序号 8 关闭兼容性评估任务后，大版本功能更新前的兼容性检查会受影响。
- 序号 10：先关闭 OneDrive 的文件夹备份；目标须为 NTFS/ReFS 固定磁盘，新文件夹权限只给本人、SYSTEM 和管理员组；有文件移动失败时该文件夹位置不改，关闭占用程序后重跑即可。
