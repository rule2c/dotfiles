# windows

## windows-optimize.bat：Windows 优化

双击运行，自动提权，按序号多选（如 `1 4 6`；`a` 执行 1-9；`q` 退出），首次执行前备份注册表到 `桌面\优化前注册表备份`。

| 序号 | 内容 |
|---|---|
| 1 | 性能：后台应用、视觉效果、电源模式 |
| 2 | 服务与开机启动项 |
| 3 | 卸载小组件 |
| 4–7 | 隐私：搜索 / 遥测 / 广告推荐 / 输入语音 Copilot |
| 8 | 禁用数据收集计划任务 |
| 9 | 清理临时文件 |
| 10 | 移动用户文件夹到其他盘（默认 `D:\Users`，不含在 `a` 中） |

使用序号 10 前先关闭 OneDrive 的文件夹备份。
